## Descrição (GitHub)
Migrar progressivamente o core de emulação do projeto (fMSX) para openMSX, mantendo boot baremetal estável no Raspberry Pi 3B e fluxo de usuário equivalente (menu, mídia, áudio/vídeo, input, persistência).

## Escopo atual
- Viabilidade técnica e arquitetura de integração do openMSX no ambiente baremetal
- Camadas host para vídeo, áudio, input e storage
- Coexistência com fMSX durante transição (fallback seguro)
- Validação de compatibilidade e desempenho para futura estabilização
