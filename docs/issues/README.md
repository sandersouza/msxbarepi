# Issues Avulsas

Este diretorio guarda o espelho local das issues remotas que ficam fora de milestone.

Convencao:

- arquivo por issue: `<numero>-<slug>.md`
- criar/atualizar primeiro o espelho local e usar esse `.md` como fonte da issue remota
- manter o historico local mesmo depois de a issue ser fechada

Quando uma issue passar a pertencer a uma milestone, o espelho local deve ser movido para `docs/milestones/m<numero>/` no mesmo ciclo de sincronizacao.
