# Template de Posts - Campanha de Financiamento

Uso: copiar, preencher placeholders e publicar.

## 1) Post de lançamento

```text
Lancei a campanha do MSX baremetal no Raspberry Pi.

Meta principal: R$ 50.000 acumulados para liberar o repositório como público para a comunidade.

Enquanto isso, vou publicar progresso técnico contínuo, builds beta e relatórios.

Se quiser apoiar: Patreon + Pix.
Se não puder apoiar agora, compartilhar já ajuda muito.
```

## 2) Post de progresso semanal

```text
Update técnico da semana:
- [entrega 1]
- [entrega 2]
- [entrega 3]

Bloqueio atual: [x].
Próximo passo: [issue #].

Meta acumulada: R$ [atual] / R$ 50.000.
Apoio: Patreon/Pix.
```

## 3) Post de urgência (hardware)

```text
Bloqueio real de hardware: [item].
Sem isso, a validação de [feature] atrasa.

Se a comunidade empurrar essa etapa, eu destravo o próximo bloco de testes ainda este mês.

Meta acumulada: R$ [atual] / R$ 50.000.
Apoio: Patreon/Pix.
```

## 4) Post de prova social

```text
Obrigado aos apoiadores desta semana: [nomes autorizados].
Vocês ajudaram a fechar [resultado técnico objetivo].

Próximo alvo: [issue/milestone].
Rumo aos R$ 50.000 para abertura pública do repo.
```

## 5) Chamada para beta-testers

```text
Preciso de beta-testers que saibam usar GitHub e abrir issues com evidência.

Se você topa testar builds e reportar bugs de forma objetiva, entre no grupo beta.
```

## 6) Versão curta EN (alcance externo)

```text
MSX Baremetal campaign is live.
Goal: BRL 50,000 total to open the repository to the community.
Support via Patreon or Pix and help accelerate real hardware validation.
```

## Checklist antes de publicar

1. Atualizar valor da meta acumulada.
2. Referenciar issue/milestone real da semana.
3. Garantir CTA com links Patreon/Pix.
4. Validar ortografia e consistência de números.
